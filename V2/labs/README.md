# Labs

Demo code and optional written labs for the V2 course. Each lab gets its own folder, named after the lecture it belongs to.

Section 1 has no lab.

| Folder | Lecture |
|---|---|
| `lab-2.4-first-bedrock-call` | 2.4 Demo: your first Bedrock call |
| `lab-3.6-model-router` | 3.6 Demo: a model router with AppConfig |
| `lab-4.5-knowledge-base` | 4.5 Demo: a Knowledge Base with an S3 source and incremental sync |
| `lab-5.4-chunking-and-reranking` | 5.4 Demo: tuning chunking and adding a reranker |
| `lab-6.4-prompt-flow` | 6.4 Demo: a versioned prompt in a Prompt Flow |
| `lab-7.5-strands-mcp-agent` | 7.5 Demo: a Strands agent with an MCP tool |
